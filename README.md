# Little Pencil Club

A free, responsive landing page for a printable children's tracing and drawing brand.

## Deployment
The GitHub Actions workflow in `.github/workflows/pages.yml` deploys the site to GitHub Pages when pushed to `main`. After the first workflow run, check **Settings → Pages** and the **Actions** tab for the live URL and status.
